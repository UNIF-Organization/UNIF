# How to contribute

If you are reading this, first of all, thank you for your interest in contributing to the UNIF Mods.

We are always working on making it easier to contribute.
For now, there are two options to contribute:
- Create a fork of this repository, make your changes in the fork and open a pull request.
- [Join our Discord](https://discord.gg/xg2Yp7mgeQ) and ask to join the dev team.

# Note on Contributed Assets and Code

When contributing to the UNIF Mods, you agree to not pursue any copyright claims against the UNIF Mods on the grounds of any contributed content, irrespective on how the assets are used within our Mods.
